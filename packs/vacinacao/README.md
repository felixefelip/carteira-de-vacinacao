# Vacinação

Package responsável pela caderneta de vacinação, vacinas, fabricantes, doses, calendário e
recomendações vacinais.

As classes não usam um namespace Ruby do package. Por exemplo, os modelos são `Caderneta`,
`Vacina` e `Dose`, e não `Vacinacao::Caderneta`, `Vacinacao::Vacina` ou `Vacinacao::Dose`.

## Dependências

O package depende da infraestrutura compartilhada do package raiz e das pessoas mantidas
pelo package Identidade.
